# 🚗 موقع عرض سيارات

واجهة ويب مخصّصة لعرض السيارات بطريقة أنيقة وسهلة الاستخدام، مبنية باستخدام **HTML + CSS فقط** (مع إمكانية إضافة JavaScript مستقبلًا). توفر تجربة مستخدم سلسة لعرض السيارات مع صورها ومواصفاتها.

---

## ✨ المميزات

* 🎨 تصميم عصري وأنيق مناسب لعرض السيارات.
* 📱 متجاوب مع مختلف الأجهزة (Responsive).
* 🖼️ عرض صور السيارات ببطاقات واضحة.
* 🔍 إمكانية إضافة مربع بحث أو فلاتر مستقبلًا.
* 🌐 دعم اللغة العربية (RTL).

---

## 📂 محتويات المشروع

* **index.html** → يحتوي على هيكل الصفحة وعناصر عرض السيارات.
* **style.css** → ملف التنسيقات لتنسيق الصفحة.
* **images/** → مجلد صور السيارات.
* **screenshot.png** → صورة توضيحية للواجهة.

---

## 🚀 كيفية الاستخدام

1. قم بتحميل المشروع أو نسخه.
2. ضع الملفات في مجلد واحد.
3. افتح ملف `index.html` باستخدام المتصفح.
4. استمتع بتجربة عرض السيارات ✨
